# BFS i DFS

## DFS:

Home PD C1 C2 TP A L BK IM

## BFS:

Home IM PD C1 A C2 TP L BK

Різниця у шляхах виникає, тому що алгоритм DFS спочатку проходить по всіх "дітях" одної вершини, переходячи від дочірньої вершини до її дочірньої вершини поки не досягне вершини без "дітей".
BFS же проходить по всіх дітях першого порядку певної вершини (всіх суміжних вершинах), переходячи до вершини наступного рівня коли всі суміжні вершини відвідані.
